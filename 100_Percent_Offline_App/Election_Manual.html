Digital Polling Booth

Official Administrator Manual

1 How to Run the System

This system is 100% offline and serverless. There is nothing to install and no commands to run.

Simply double-click the PollingBooth.html file to open it in your web browser (Chrome/Edge).

Critical Warning

All data is saved securely in your browser's local memory. Do NOT clear your browser history or cache while an election is actively running, or you will lose the vote data.

3 Election Day Workflow

Step 1: Add Candidates

Go to the Admin Dashboard → Candidates tab. Add the names of all the students who are running for the election.

Step 2: Start Election

Go to the Admin Dashboard → Election tab. Click "Initialize Election". The status will change to LIVE & ACTIVE.

Click "Back to Kiosk" to return to the voting screen. The system is now ready for voters.

Step 3: Voting

  • The student steps up to the computer and types their Roll No (1-30).
  • The system will verify them and present the ballot.
  • They click on the candidate they want to vote for.
  • The system records their vote and resets for the next student.

* Note: A roll number can only be used once. If a student tries to vote twice, the system will block them.

4 Results & Maintenance

Viewing Results

Once voting is completely finished:

  1. Go to the Admin Dashboard → "Election" tab and click "Halt Election".
  2. Go to the "Results" tab and enter the Results Lock Password to see the final vote tally.
  3. Check the "Audit" tab to see exactly which roll number voted for which candidate.

Resetting the System

If you want to run a new election or clear test data:

  1. Go to the Admin Dashboard → "Election" tab.
  2. Click "Purge Database".

This will completely wipe all votes and reset the identity register so you can start fresh. It will NOT delete your candidates.
